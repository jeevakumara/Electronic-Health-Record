Medical Update & Prescription Mutation

Modifying a prescription automatically triggers MariaDB's WITH SYSTEM VERSIONING engine, archiving the existing record into hidden history partitions.

ℹ️ System-Versioning Mechanism: When you click "Apply Medical Update", the server executes an SQL UPDATE. MariaDB natively closes the timestamp on the existing row, stores it in the temporal partition, and assigns the updated data a new start timestamp without data loss.
